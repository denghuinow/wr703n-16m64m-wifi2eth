WR703N-16M64M Wi-Fi → 网线

连接上级 2.4 GHz Wi-Fi，然后把网络输出到 RJ45。扫描结果可直接点选；隐藏 SSID 仍可手工输入。

点击扫描，然后点选要连接的 SSID。

NAT：有线设备获得 192.168.77.x，兼容性最好。
relay：有线设备通常直接从上级 DHCP 获取地址，仅 IPv4，行为更接近无线网桥。

当前 OpenWrt 25.12.5 有 relayd 长时间运行后停止转发的已知报告，因此默认选 NAT；确实需要同网段时再选 relay。

Setup 热点为开放网络，仅在首次启动或长按 Reset 5～14 秒后出现。短按 Reset <1 秒重启；长按 ≥15 秒恢复出厂。
